## 移动端适配落地（已提交，未推送）

- 用户决定：暂停小程序/App 方向，优先做零依赖的移动端适配（不引入数据库、不改部署架构）。
- 关键前提：`app/layout.tsx` 新增 `viewport` 导出并设 `viewportFit: 'cover'`，否则所有 `env(safe-area-inset-*)` 不生效；`lang` 由 `en` 改为 `zh-CN`。
- `app/globals.css` 新增安全区工具类 `pt-safe-3/4`、`pb-safe-4` 与 `-webkit-text-size-adjust` / `-webkit-tap-highlight-color`。用法约束：**只能与不同方向的 padding 搭配**（如 `px-4 pt-safe-4 pb-4`），不可与 `p-4`/`py-4` 共存，否则覆盖顺序不确定。
- 修复的实际缺陷：
  1. 首页 `nav` 为 `hidden md:flex`，手机端导航整体消失，AI 口语对练/生词本入口丢失 → 新增 Sheet 抽屉式移动菜单。
  2. freetalk 生词本面板固定 `w-80`，375px 屏打开会挤掉对话区 → 移动端改为 `fixed inset-0` 全屏覆盖，`md:` 保持侧边栏。
  3. freetalk 根节点 `min-h-screen` + 内部 `flex overflow-hidden` 导致底部输入框被地址栏遮挡 → 根节点改 `h-dvh`（非 min-h）。
  4. 练习页长标题挤压「下一题」按钮 → `min-w-0` + `truncate` + 按钮 `flex-shrink-0`。
  5. 练习页底部操作栏被 iPhone Home 指示条遮挡 → `pb-safe-4`，按钮移动端全宽。
- 全站 `min-h-screen` → `min-h-dvh`，规避移动浏览器地址栏伸缩高度跳变。
- 更正此前判断：Input/Textarea 已是 `text-base md:text-sm`（16px），不存在 iOS 聚焦缩放问题。
